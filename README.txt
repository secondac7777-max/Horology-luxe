HOROLOGY LUXE — starter website
=================================

Files:
- index.html: homepage and sample editorial sections
- style.css: responsive luxury visual design
- script.js: mobile navigation and demo newsletter form

Preview locally:
1. Extract this ZIP.
2. Open index.html in a browser. An internet connection is needed for the remote fonts and photography.

Publish free with GitHub Pages:
1. Sign in or create an account at https://github.com/
2. Create a new public repository named horology-luxe.
3. Upload index.html, style.css, and script.js to the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
6. Wait for the published URL shown in Pages settings.

Before launch:
- Replace hello@example.com with a real contact address.
- Connect the newsletter form to a real email provider or remove it.
- Add researched, original articles and real affiliate links after program approval.
- Verify product prices, availability, specifications, and claims before publishing.
- Add a privacy policy appropriate to the tools and jurisdictions you use.
- This is a front-end starter, not a complete CMS or live affiliate tracking setup.
- Remote Unsplash images and Google Fonts require an internet connection. Check image licenses and usage terms before commercial publication.
